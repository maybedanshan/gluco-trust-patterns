01 — 核心发现

三个数字，讲完整个项目

以下全部数值来自本地可复现实验，括号内为参与者级 bootstrap 95% 置信区间。TIR 误差单位为百分点（pp），血糖误差单位为 mg/dL。

02 — 研究模块

一套数据，三层递进

GlucoTrust 回答"报告可信吗"，GlucoPatterns 回答"个体化值多少"，联合实验把两者接起来：缺失如何侵蚀个体化收益。

GlucoTrust · 缺失 → 指标失真

随机 / 连续 / 夜间三种缺失模式，测量时间加权平均血糖与 TIR 的有符号偏差与绝对误差；双 CGM（Dexcom + Libre）同窗对照，24/48/72 小时窗口敏感性分析。

实验总量 64,440 次，另含 PhysioCGM 原始导出的 317 个候选时间缺口审查。

GlucoPatterns · 餐后个体化预测

1,706 条餐次记录 → 1,179 个合格餐；留出参与者外层评估，岭回归 + 收缩式早期历史偏移，比较训练集均值、合并模型与个体化模型。

严格按参与者划分数据、预处理仅拟合训练集。

联合实验 · 缺失 × 个体化

固定预测目标与测试集，只改变早期历史的缺失比例与模式；将损失分解为"可用性成本 + 保留特征成本"，明确归因到机制而非黑箱。

见 交互式结果看板（中文）。

04 — 边界声明

我们刻意不做的事

诚实标注边界与"给出漂亮结论"同样重要。

不用于临床研究原型，不用于诊断、治疗决策或饮食用药建议。
不解释真实掉线CGMacros 发布曲线含插值，实验测的是"发布后额外缺失"，不是原始传感器故障机制。
不做因果归因缺失模式对比为描述性发现；分解仅用于诊断，不构成因果声明。
不做显著性滥用种子不是独立样本；按参与者 bootstrap，不做池化显著性推断。
单嘉诚 Jiacheng Shan
