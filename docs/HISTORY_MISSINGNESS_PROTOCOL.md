# Personal-history input missingness: protocol 1.0

Exploratory extension specified after inspecting the first GlucoPatterns results, before running this joint experiment. Not preregistered.

Primary history budget: the first 10 eligible meals. Retain the same 44-person, 739-later-meal evaluation set from the original benchmark. Global ridge models train only on other people, with unchanged features, standardization, participant weighting and penalties. All original nutrition, meal times, adaptation labels and test features/labels remain fixed. Only released CGM inputs to historical premeal features are degraded. This isolates input degradation, not simultaneous loss of historical labels.

For each person, define one history timeline from 30 minutes before the first adaptation meal through one minute before the tenth meal. Mask supported observed Dexcom minute values in that interval at requested fractions 0/5/10/20%, using seeds 0–9, random sampling, one contiguous index block, or random sampling restricted to 00:00–06:00. Time support is fixed at one minute per observed released value; no native gap is bridged. A block is contiguous in observed index space and may span pre-existing gaps. Budgets apply to the entire history timeline, not only to the premeal features; record actual premeal exposure separately. Do not concentrate night masks into daytime premeal windows merely to force an effect.

If the requested night budget exceeds the available night support, mark that run infeasible. Do not substitute a different mechanism or remove its participant from the reported eligible cohort. Suppress aggregate contrasts for any incomplete configuration.

Recompute each history meal's premeal mean from retained one-minute supports without interpolation. Recompute change per minute using the earliest and latest retained premeal values and their elapsed interval. Retain an adaptation meal only if at least 15 of its 30 premeal minutes remain (and two distinct timestamps). Otherwise omit that meal from adaptation, but retain the person's original later test meals. The personal offset remains residual sum / (usable history count + 5); with zero usable history it falls back to the pooled model. Both feature degradation and this prespecified adaptation-availability response are part of the estimand.

For every run, report pooled and personalized later-test MAE, clean-history personalized MAE, usable history meals, timeline missing fraction and fraction of premeal minutes removed. Average errors across seeds within each person, then weight people equally. Main contrasts: pooled minus degraded-personalized MAE (remaining personalization benefit) and degraded minus clean-personalized MAE (degradation cost). Positive benefit favors personalization; positive cost means missingness worsened it.

Compute 95% percentile pointwise intervals from 10,000 participant bootstrap draws, seed 20260915. Share participant draws across complete configurations and contrasts. Do not treat seed runs as independent people. These intervals are conditional on the fitted overlapping leave-person-out folds and do not include full refitting uncertainty. No multiplicity correction or confirmatory claim. Night effects must be interpreted with actual overlap with model inputs; zero overlap is not proof of general robustness to nighttime missingness.

Source interpolation and unknown nutrition-record availability still prevent a real-time forecasting claim. This experiment does not simulate loss of full meal records, nutrition metadata or outcome labels. Historical label degradation and other history budgets require separate extensions.
