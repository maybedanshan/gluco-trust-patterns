# Project working instructions

## Action logging (explicit user preference)

After each actual operation, append a concise entry to ACTION_LOG.md recording the actual completion time in Asia/Shanghai (UTC+08:00), the action, outcome, and affected files or artifacts. This includes inspections, edits, commands, experiments, tests, browser operations, and failures. A batch of closely related tool operations can use one entry with each outcome stated. Append promptly before the next unrelated operation. Never invent past timestamps or claim an attempted operation succeeded without evidence. Do not log sensitive data, credentials, or individual health records. Log writing itself does not require another entry. Preserve existing log entries; correct errors with a new entry.
